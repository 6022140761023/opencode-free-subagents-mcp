# OpenCode 免费子代理集群（轻量接入层）

本插件仅保留薄连接层（`node ./run-mcp.mjs` 桥接本机唯一的 `http://127.0.0.1:8787/mcp` 后端），所有模型同步、失效替换与默认主力分配均由后端统一管理，客户端不写死具体模型名称。

## 核心使用边界（约 200K 上下文限制）

- **适用场景**：聚焦小任务、局部代码/Diff 审查、单文件或少数核心文件分析、独立函数/脚本编写、多视角交叉验证。
- **避免场景**：不要将大型仓库、几十个无关文件或巨型日志一次性传给子代理。先用 `Read` / `Grep` 精确定位范围，仅传递精简片段或少量关键文件（`file_paths` 后端限流 120,000 字符）。

## MCP 工具调用（动态解析现役模型）

- **`list_free_models`**：实时获取后端现役免费模型列表、思考挡位与当前推荐组合。
- **`run_subagent`**：向单个免费子代理委派聚焦任务。可省略 `model`（由后端自动选现役旗舰）或指定 `list_free_models` 返回的任意模型 ID。
- **`parallel_subagents`**：并行召集多模型会诊。直接传入 `prompt`（和可选 `file_paths`）即可自动唤醒后端当前推荐的 3 席团队；也可自定义 `tasks` 数组。

## 标准工作流

1. **先精简输入**：自己先用 `Read` / `Grep` 裁出问题焦点，只把必要上下文交给子代理。
2. **灵活派发**：单点任务用 `run_subagent`，需要交叉验证用 `parallel_subagents`。
3. **主控核实**：子代理结论仅供线索参考，关键代码事实需你亲自核对后输出。
4. **排障**：正常情况下首次调用会自动后台拉起代理服务；如仍异常，可用 `Bash` 检查 `http://127.0.0.1:8787/health`。
